# NURZING — Premium Home Nursing, On Demand

A new-age nursing bureau website. Single-page, self-contained static site (no build step, no dependencies) — just open `index.html`.

## Highlights
- Deep teal + warm gold "clinical luxe" palette, editorial serif/sans typography
- Asymmetric hero with a live "care match" card
- **Hassle-free booking matcher** — 3-step flow with a live, transparent price estimate
- Expandable service list with indicative rates
- Bento "why us" grid, stats, testimonials, FAQ accordion, responsive down to 360px

## Run locally
Open `index.html` directly, or serve it:

    python3 -m http.server 8000

## Deploy
Any static host works — GitHub Pages, Cloudflare Pages, Netlify, Vercel.

---
NURZING is a nursing bureau / placement service. Indicative rates in the site are for guidance and are confirmed by a care advisor.
